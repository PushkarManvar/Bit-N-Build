# Security Policy

JourneyLens is a hackathon prototype that uses synthetic data only.

## Never commit

- `.env` files
- API keys or access tokens
- database credentials beyond local example defaults
- real customer names, email addresses, phone numbers, orders, or support notes
- exported production datasets

## Reporting

Open a private security advisory in the GitHub repository when available. Do not include exploitable secrets or real PII in a public issue.

## Identity safety

Changes that allow name-only auto-merging or bypass strong-identifier conflict checks are security-sensitive and must not be merged.
